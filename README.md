# Surat Romantis

Aplikasi web sederhana untuk menulis dan menyimpan surat romantis di browser menggunakan localStorage.

## Fitur
- Tulis surat romantis dengan nama penerima, pengirim, dan pesan
- Surat otomatis tersimpan di browser (localStorage)
- Animasi floating hearts yang romantis
- Tampilan responsif untuk mobile dan desktop
- Baca surat yang sudah ditulis
- Hapus surat jika ingin menulis yang baru

## Cara Menggunakan
1. Buka `index.html` di browser
2. Isi nama penerima, pengirim, dan pesan
3. Klik "Kirim & Simpan"
4. Klik "Baca Surat" untuk membaca surat yang sudah ditulis

## Tech Stack
- HTML5
- CSS3 (inline)
- Vanilla JavaScript (inline)
- localStorage untuk persistensi data

## Deploy ke GitHub Pages
1. Push repo ini ke GitHub
2. Buka Settings > Pages
3. Pilih Source: main branch
4. Akses aplikasi via `https://<username>.github.io/<repo-name>/`

## Catatan
- Data disimpan di browser yang sama (localStorage)
- Jika clear browser data, surat akan hilang
- Tidak ada backend atau database yang digunakan
